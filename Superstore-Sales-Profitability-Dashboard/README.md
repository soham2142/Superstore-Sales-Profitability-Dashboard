# Superstore Sales & Profitability Dashboard

## Project Overview
This project analyzes sales and profitability across product categories, sub-categories, regions, and customer segments to identify business trends and performance opportunities.

## Objectives
- Analyze overall sales, profit, and order performance
- Compare sales and profitability across categories and regions
- Identify high-performing and loss-making product areas
- Explore the impact of discounts on profitability
- Present business insights through visualizations and a dashboard

## Tools & Technologies
- Python
- Pandas
- NumPy
- SQL
- Excel
- Power BI
- Matplotlib
- Seaborn

## Project Workflow
1. Data Overview
2. Data Cleaning & Preparation
3. Sales Analysis
4. Profitability Analysis
5. Category & Regional Analysis
6. Dashboard & Business Insights
